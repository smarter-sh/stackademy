# Your First AI Application

A tutorial in six parts on [blog.smarter.sh](https://blog.smarter.sh/category/tutorials/): you build Stanley, Stackademy's AI course advisor, from a chatbot with a prompt to an application that searches Stackademy's course catalogue, its course database and its student handbook, inside guardrails. Each part's folder holds the files that the part creates or changes, finished, so that you can compare your work with them, or catch up.

| Part | Folder |
| --- | --- |
| [Part 1: An OpenAI Chatbot in the Prompt Engineering Workbench](https://blog.smarter.sh/2026/11/23/first-ai-application-part-1-workbench/) | [`part-1/`](part-1/) |
| [Part 2: The YAML Manifest Is the Application](https://blog.smarter.sh/2026/11/23/first-ai-application-part-2-yaml-manifest/) | [`part-2/`](part-2/) |
| [Part 3: Calling a REST API With an ApiPlugin](https://blog.smarter.sh/2026/11/23/first-ai-application-part-3-rest-api/) | [`part-3/`](part-3/) |
| [Part 4: Querying a SQL Database With a SqlPlugin](https://blog.smarter.sh/2026/11/23/first-ai-application-part-4-sql-database/) | [`part-4/`](part-4/) |
| [Part 5: LLM Guardrails That Keep a Chatbot Safe and On Topic](https://blog.smarter.sh/2026/11/23/first-ai-application-part-5-guardrails/) | [`part-5/`](part-5/) |
| Part 6: Searching Your Own Documents With a Vectorstore (coming soon, in the [Tutorials](https://blog.smarter.sh/category/tutorials/) category) | [`part-6/`](part-6/) |

The parts build on each other: Part 4's `course-advisor.yaml` lists the tools of Parts 3 and 4, and so on. Apply a part's files only after the parts before it.

Stackademy is a fictional online code academy. Its course database and course catalogue api come with every Smarter platform, so the tutorial works on a platform on your own computer. See the [repository's README](../../README.md).
