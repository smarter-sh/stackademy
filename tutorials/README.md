# Tutorials

The finished files of the tutorials on [blog.smarter.sh](https://blog.smarter.sh/category/tutorials/) that use Stackademy.

- [Your First AI Application](first-ai-application/): build Stanley, Stackademy's AI course advisor, in six parts.

A Smarter platform never loads this folder when it loads this repository: these are the resources that each tutorial's readers build themselves, step by step. The repository's checks still validate every manifest here, so that the tutorials' files keep working as Smarter changes.
